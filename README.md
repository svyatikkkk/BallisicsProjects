# BallisicsProjects
Программы различных баллистических расчётов, выполненные в виде консольного приложения с записью в файлы типов .csv и .txt
1) AtmosphereCalculator - выполняет расчёт параметров атмосферы. На ввод подается геометрическая высота, в качестве результата выводится в консоль геопотенциальная высота, давление, температура, плотность, скорость звука и ускорение свободного падения на соответствующей геометрической высоте. Результаты проверены по ГОСТ 4401-81 "Атмосфера стандартная".
2) BoostCoastPhaseTrajecoryCalculator - выполняет численное моделирование траектории полета ЛА на АУТ (Активном участке траектории) и ПУТ (Пассивном участке траектории). Интегрирование уравнений движения происходит с помощью трёх численных методов: Метод Эйлера, Модифицированный метод Эйлера и метод Рунге-Кутты 4-го порядка. Также можно запустить одновременное интегрирование тремя методами и сравнить полученные данные. Результаты записываются в .csv файл, что существенно упрощает их дальнеший анализ.
3) KeplerToKinematicCalculator - выполняет перерасчет кинематических параметров движения в Кеплеровы элементы орбиты. Чтение данных происходит из файла input.txt в котором записаны проекции вектора скорости и проекции радиус-вектора. Результаты записываются в файл output.txt
4) OverloadTrajectoryCalculator - выполняет численное моделирование полета ЛА с боковыми перегрузками nza. Расчёт производится путём интегрирования уравнений движения методом Рунге-Кутты 4-го порядка. Также реализована интерполяция контрольных точек. Итоговый результат записывается в файл .txt.
